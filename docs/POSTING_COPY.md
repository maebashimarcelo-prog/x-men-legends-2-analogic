## C. MarvelMods forum post

**XML2 Modern Controller v0.5.0-beta.1 [Public Beta]**

The PC port receives continuous axes but drops components below 0.75, losing
diagonals and intermediate directions. This standalone x86 proxy corrects the
movement gate in memory and adds radial deadzone, partial-stick speed,
hot-plug/reconnect and dynamic Xbox/PlayStation glyphs. XMen2.exe is not
permanently changed. Generic controllers default to Xbox presentation.

ConsoleDefault uses RB Health Pack, LB Energy Pack and LT Call Allies. Existing
custom bindings are preserved unless explicitly restored. Advanced retains
original navigation, with South/A Accept and East/B Back; edit bindings via
mouse/keyboard. Incompatible writers intentionally keep textual labels.

Validated EXE SHA-256:
146CD9C316EDB57A267CD73753A7CE9AF647E52AAB750D449C6B278FB4A1669B

P1 is the main tested path. P2–P4 and native PlayStation hardware need community
tests; the PlayStation glyph style has been validated via override. Other EXEs
are not claimed supported and refuse incompatible hooks. Please report other
EXE hashes/controller models with connection, player slot, config and log details.
Do not attach game files.
